## 왜 블로그를 시작했나

배운 것들을 기록하지 않으면 금방 잊는다는 걸 몸소 느꼈다.

그래서 시작한다. 완벽하지 않아도 괜찮다. **일단 쓰는 것**이 목표다.

## 이 블로그에 쓸 것들

- 개발하며 배운 것들
- 삽질 기록 (중요)
- 가끔 일상

## 코드 예시

```typescript
const hello = (name: string) => {
  return `안녕하세요, ${name}`;
};

console.log(hello('sevin'));
```
